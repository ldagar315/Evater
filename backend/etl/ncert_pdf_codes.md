# Verified NCERT PDF codes (classes 6-10, 2025-26 books)

Source: ncert.nic.in/textbook.php directory listing, verified 2026-10-21.

- Class 6: fecu1 (Curiosity, Science), fegp1 (Ganita Prakash, Maths)
- Class 7: gecu1 (Curiosity, Science), gegp1 (Ganita Prakash, Maths)
- Class 8: hecu1 (Curiosity, Science), hegp1 + hegp2 (Ganita Prakash Part 1 / Part 2)
- Class 9: iesc1 (Science, NEW rationalised book), iemh1 (Maths, NEW book)
- Class 10: jesc1 (Science, OLD book layout), jemh1 (Mathematics, OLD book layout)

Chapter PDF URLs follow https://ncert.nic.in/textbook/pdf/<code><NN>.zip or .pdf
per chapter, e.g. hegp101.zip = class 8 Ganita Prakash part 1 chapter 1.

Layout notes:
- Class 9 books: 13 chapters (science), no "Figure it Out"/"Page No." markers -
  needs per-chapter section discovery.
- Class 8 Ganita Prakash part 1 ships an in-chapter answer key ("Page No. N",
  "Ans."/"Ans:" variants); part 2 ships no key.
