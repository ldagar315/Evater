# Original Class 8 mixed-chapter practice

Two independently authored Evater papers, each 24 questions / 60 marks / suggested 150 minutes. Twelve objective questions, six short answers, four extended answers and two case questions. Model answers and marking guidance follow the questions. Not official CBSE or NCERT papers; this is selective topic sampling, not every syllabus skill or a certified school exam pattern. Suggested timing is editorial, not student-calibrated.

Maths samples all 14 current chapter categories; Science all 13. The 48 questions contain 21 questions reused from our independently authored 24-question reasoning review pack and 27 additional original paper questions. This is not 48 new bank questions. No database import. Existing 27 chapter PDFs are unchanged.

The JSON files are editable source. `render.py --release` creates student-facing PDFs using ReportLab and DejaVu fonts. Output names are mathematics-practice.pdf and science-practice.pdf; copy them to the two public mixed-chapter PDF filenames. Rendering without the flag creates private watermarked review PDFs.

Question background sources are recorded in JSON, not instructions or borrowed questions. Geometry/data textbook origin requests temporarily failed, so their actual chapter text was also checked at these mirrors:
- https://pdf.ncertarchive.com/ncert-books/new/2026/class-8/mathematics/class-8-maths-chapter-11.pdf
- https://pdf.ncertarchive.com/ncert-books/new/2026/class-8/mathematics/class-8-maths-chapter-12.pdf

Public format research: Delhi's Class 8 Maths practice paper uses a 60-mark / 2.5-hour format, but that is one local example, not a universal CBSE rule:
https://edustud.nic.in/edu/PracticePaper26_27/8/PP2026_Class_8_Math_EM.pdf

No competitor question text, diagrams or third-party PDFs are included. No ranking guarantee. Website cards state actual counts and distinguish mixed practice from chapter revision.
