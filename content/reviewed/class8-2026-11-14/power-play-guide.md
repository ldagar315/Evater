# Power Play: make the multiplication visible


A power is a short way to record repeated multiplication. The useful question is not "Which rule do I remember?" It is "What multiplication does this expression represent?"

## Read the base and exponent differently

In 7^3, the base is 7 and the exponent is 3. It means 7 x 7 x 7 = 343. It does not mean 7 x 3.

Try saying the expression aloud as "three factors of seven" before calculating. That wording makes the job of each number clear.

## Build the exponent rules instead of guessing them

Consider 6^2 x 6^3. The first part has two factors of 6 and the second has three. Together they have five, so the result is 6^5. We add exponents because we are counting factors of the same base.

Now compare 6^2 + 6^3. This is addition of two numbers, not one long product of sixes. It is 36 + 216 = 252, not 6^5. A rule belongs to an operation; changing the operation changes the reasoning.

For a power of a power, (4^2)^3 means three copies of 4^2 multiplied together. Each copy contains two factors of 4, making six factors altogether. So (4^2)^3 = 4^6.

## Change the form without changing the number

Since 9 = 3^2, we can write 9^3 as (3^2)^3 = 3^6. Rewriting both expressions with a common base can make comparison easier.

For example, compare 8^2 and 2^7. The first becomes (2^3)^2 = 2^6. Six factors of 2 make 64, while seven make 128. The comparison is now visible.

Do not rewrite a number merely to make the page look complicated. A common base is useful when it simplifies the calculation or comparison.

## Zero and negative powers are not zero and negative answers

For example, 5^3 / 5^3 = 1. The same-base division rule writes that quotient as 5^(3-3) = 5^0, so 5^0 = 1. More generally, a nonzero base raised to zero equals 1. This statement does not define 0^0.

Following the sequence down by dividing by 5 gives 5^1 = 5, 5^0 = 1, 5^-1 = 1/5, and 5^-2 = 1/25. The negative exponent tells you to use a reciprocal. It does not put a minus sign in front of the answer.

## Scientific notation keeps scale in view

Write 63,000 as 6.3 x 10^4. The coefficient is at least 1 and less than 10, and the power of ten records the scale.

For a small positive number, 0.00063 = 6.3 x 10^-4. Check by moving from 6.3 to the original number through four divisions by 10.

When comparing positive quantities in scientific notation, compare the powers of ten first. If those match, compare the coefficients. This is more reliable than counting a long string of zeros each time.

## A short self-check

1. Expand 3^4 as a product before calculating it.
2. Explain why 3^2 x 3^4 is 3^6, but 3^2 + 3^4 is not.
3. Rewrite 16^2 using base 2.
4. Explain why 10^-3 is positive, even though its exponent is negative.
5. Put 0.0048 into scientific notation and check the value by multiplying back.

Review key: 3 x 3 x 3 x 3 = 81; the product joins six factors but the sum is 9 + 81 = 90; 16^2 = (2^4)^2 = 2^8; 10^-3 = 1/1000; 0.0048 = 4.8 x 10^-3.
